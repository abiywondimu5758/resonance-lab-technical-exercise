# RESONANCE Lab technical exercise

## Requirements

Node.js 20 or newer. No third-party dependencies or environment variables are required.

## Development

```sh
npm run dev
```

Open http://127.0.0.1:5173. Stop the server with Ctrl+C.

## Build and preview

```sh
npm run build
npm run preview
```

Stop the development server before starting preview; both use port 5173. Build output is written to `dist/`.

## Project layout

- `public/`: HTML, CSS and JavaScript.
- `scripts/`: local server and static build tooling.
- `RESONANCE_Website_Assessment.pdf`: assessment and priorities.
- `design/`: wireframes and visual designs.

## Current implementation

The shared header, university identity, responsive navigation, mobile menu and contact footer are implemented. The homepage now includes the hero, research themes, participation routes, previous-cycle notice and partner marks. Supporting routes contain page shells; detailed content follows separately.
