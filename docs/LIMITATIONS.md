# Known limitations

- The prototype includes the requested homepage and eight supporting pages. Total hands-on time was not continuously tracked; see WORK_LOG.md.
- Image and portrait areas in the checked-in files are still labelled placeholders. The AAU crest is from the official AAU site; partner artwork is cropped from source evidence. Approved originals and real lab photos are needed for production.
- Publication records are not supplied because the original entries were templates. No papers or achievements were invented.
- The 2025/26 call is historical. Current recruitment status, source eligibility differences and staff listings need academic-owner confirmation before production use.
- The source's placeholder telephone is omitted. The public email and institutional postal address are retained.
- Supporting pages use source snapshot content. Its presence in the original site is not independent verification that every time-sensitive claim remains current.
- Browser checks used native Chrome and responsive emulation, not physical phones or screen-reader testing. No full accessibility certification, analytics, Lighthouse score or production performance result is claimed.
- Static page headers/footers are duplicated. There is no CMS, database, search, backend or application-processing workflow. The historical external application form is not presented as a current application endpoint.
- The included server is local review tooling, without production TLS, monitoring or deployment configuration. Deployment is not required.
- Design PDFs contain cropped review views of long detail pages; the SVG packages contain full layouts. They are vector drawings, not browser screenshots, native Figma files, Auto Layout or an interactive Figma prototype.
